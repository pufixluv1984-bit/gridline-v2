# Дизайн

Источник истины — дизайн-проект «Gridline — редизайн, главная (тёмный глянец)» в Claude Design:
https://claude.ai/artifact/Yc5wjxTmWFKF7CbkJaJhFi (slug `fff1608c-0dbb-4678-983e-becf4d652d0d`). Каждый экран есть в двух размерах: 1440 и 2K (`*-2K.dc.html`). Если макет и текст в `docs/` расходятся, главнее макет.

## Как читать макеты

Файлы `project/*.dc.html` — это разметка в формате Claude Design (`<x-dc>`, `sc-for`, `sc-if`, класс `Component extends DCLogic`). Их **нельзя** класть в приложение как есть: это эталон для пересборки на React. Из макета берём вёрстку, CSS, размеры, анимации и состояния; примерные данные (`DRVS`, `CONS`, `FAQ` и т.п.) заменяем данными из базы. Ссылки между экранами (`href="Main.dc.html"`) заменяются роутами.

Как достать файлы:
1. **Основной способ.** Читать экраны по одному из артефакта (slug выше) инструментом `read_file` коннектора артефактов, непосредственно перед тем как делать этот экран. Нужны: сессия под аккаунтом владельца и подключённый коннектор артефактов. Фото и ресурсы брать через `read_asset`/`list_assets`.
2. **Запасной.** Если у владельца есть экспорт проекта, он лежит в `design/` (`project/*.dc.html`, `project/canvas.json`, фото). Тогда читать оттуда.
3. Нет ни того, ни другого: остановиться и сообщить владельцу.

Начинать с экранов фазы 1: Auth-Login/Register/Reset, Lobby-*, Main, Predict, League, Results, Schedule, Profile, Settings, Overlays, Empty-States, Error-*. Фэнтези-экраны читать только в фазе 4.

## Токены (из экранов фэнтези/лиги; сверить с Main)

- Фон страницы `#07070a`, внутренняя область `#0a0a0d`, контент `#0b0b0e`, рамка-корпус градиент `#141418 → #0e0e11`.
- Карточки: радиус 24, градиент `#121216 → #0d0d10`, рамка 1px `rgba(255,255,255,.07)`, внутренний верхний блик `inset 0 1px 0 rgba(255,255,255,.04)`.
- Текст `#f3f3f5`, приглушённый `#9a9aa4`.
- Акцент (красный F1) `#e8211a`, свечение `accent + 55` (альфа). Варианты акцента в макете: `#e8211a #ff3b30 #ff5a1f #f5c400`.
- Золото/профиль и лидер: `#ffd400`.
- Положительное `#7fe0a0`, отрицательное `#ff7a70`.
- Шрифты: Inter (текст), Space Grotesk (числа, таймеры, очки; `font-variant-numeric: tabular-nums`).
- Кнопки и вкладки — таблетки (радиус 999), основная кнопка светлая `#f3f3f5` с пульсирующим свечением; активная вкладка светлая с тёмным текстом.
- Анимации: появление карточек `rise` (с задержкой по индексу), бегущая точка по трассе, мигающая «live»-точка. Учитывать `prefers-reduced-motion`.
- Масштаб для больших экранов: в макете ступеньки `zoom 1.2` от 1800px и `1.4` от 2300px внутри рамки 1760px. На сайте рамки нет, масштаб плавный (`src/lib/uiScale.ts`): `body { zoom }` = окно / 1440 от 1 до 1.4 (2K), выше 2K плавно до 1.7 (4K). Колонка контента не шире 1760px (в единицах до увеличения). Режим «широко» (`html[data-wide]`, раскладка от 2000px: 4K, сильное отдаление): меню закреплено раскрытым, колонка до 2100px, свечение по краям. Сетки добавляют колонки по ширине колонки контента (`@container page`), а не окна — медиазапросы `min-width` для широких экранов не использовать. Размер текста не мельче 11–12px, контраст не ниже 4.5:1.
- Подсказки `?` при наведении (`.hint` + `.tip`) используются как встроенное объяснение правил — сохранить.

Токены вынести в `src/styles/tokens.css` как CSS-переменные; не раскидывать значения по компонентам.

## Каркас

Боковая панель 72px (профиль «TS» сверху, затем: Главная, Прогнозы, Фэнтези-лига, Результаты F1, Календарь, Лига друзей), справа внутренняя область: заголовок, панель вкладок/кнопок, контент, футер. Футер: полный (с колонками ссылок) на экранах с панелью, тонкая строка на экранах входа и ошибок. Текст футера (неофициальный фан-проект) оставить как в макете.

## Ресурсы

Фото пилотов (`photos/drivers/*.png`), машины (`photos/cars/*.webp`) и схемы трасс лежат в дизайн-проекте как ассеты (`/_blob/...`). Подключать через один модуль `src/lib/assets.ts`, чтобы заменить на монограммы без правок по коду. Права на фото принадлежат владельцам; см. правило 10 в `CLAUDE.md`.

## Откуда брать ресурсы

| Что | Источник |
|---|---|
| Фото пилотов, болидов, логотипы команд | Готовый набор владельца, приходит отдельным архивом. Claude Code сам распаковывает его в `public/assets/`, сохраняя структуру папок и имена как в архиве, и смотрит, как там всё лежит. Из дизайна их не вытаскивать. Подключать через один модуль (правило 10 в `CLAUDE.md`) |
| **Трассы** | **Только из дизайна.** Берутся нарисованные вручную новые SVG из экрана `Tracks.dc.html`. Старые трассы из набора владельца и из старого сайта **не использовать** |

Как сделать трассы: открыть `Tracks.dc.html`, вынести каждую трассу в отдельный файл `public/assets/tracks/<slug>.svg` (slug по названию Гран-при, список из `docs/PRODUCT.md`), без изменения линий и цветов; в экране подгружать нужную трассу по требованию (правило 11). Если в наборе владельца есть папка со старыми трассами, игнорировать её.
